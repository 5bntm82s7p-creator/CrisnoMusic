CRISNO SITE — QUICK SETUP

1. Upload every file and folder in this ZIP to your GitHub repository.
2. Keep index.html, style.css, and script.js in the repository root.
3. Your optional custom photo should be named:
   assets/artist.jpg

4. Replace every href="#" in index.html with your real links:
   Spotify, Apple Music, TikTok, Instagram, YouTube, merch store, etc.

5. Replace:
   yourbusiness@email.com
   with your actual business email.

6. The Preview button is currently a visual demo. To use a real audio file:
   - Put a 30-second MP3 in assets/
   - Add an <audio> element in index.html
   - Connect it in script.js

7. GitHub Pages:
   Settings → Pages → Deploy from branch → main → /root

The site works without any images because the album and merch visuals are built in CSS.
